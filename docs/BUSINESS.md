# 轉磚的商業模式（草案）

一句話：**免費玩，賣外觀和會員，不賣強度。**

這份文件分成四塊：怎麼賺錢、金幣怎麼流動、現在遊戲裡已經做到哪、要真的收錢還缺什麼。最後是風險，其中智財風險請務必先看。

---

## 1. 收入來源

| 層級 | 內容 | 暫定價格 | 目前狀態 |
|---|---|---|---|
| 會員訂閱（主力） | 用自己的圖片當牆面和磚面、全部外觀隨便換、金幣 +50%、簽到雙倍、錄影保留 30 場 | 月費 NT$90、年費 NT$890 | 遊戲內已做，**體驗模式，不扣款** |
| 外觀（金幣換） | 磚樣式、牆面、主題、消行特效、整套風格（打 75 折） | 400–1,200 金幣 | 已做 |
| 道具（金幣換） | 七種道具，帶進一般對戰和分身對戰，每場最多 2 個 | 40–60 金幣 | 已做 |
| 整套風格直購（之後） | 給不想訂閱的人一次買斷 | NT$60–150 | 未做 |
| 賽季通行證（之後） | 每月一條獎勵線，免費線加付費線 | NT$120 | 未做 |
| 獎勵式廣告（之後，可選） | 看一段廣告拿金幣，不看也不影響遊戲 | — | 未做 |

**為什麼訂閱是主力。** 這款遊戲單場只有兩分鐘，玩家會反覆回來，外觀又能一直出新的，訂閱比一次買斷更合適。「用自己的圖片」是只有訂閱才有的東西，別的外觀再多也替代不了，這是訂閱最主要的理由。

**金幣包要不要賣。** 建議先不要。金幣能買道具，道具會影響勝負；一旦金幣能用錢買，就變成花錢買強度。現在的設計是金幣只能靠玩拿到，排位賽和連線對戰又不能帶買來的道具，所以公平性站得住。之後如果要賣金幣包，至少守住兩條：排位和連線維持不能帶道具；金幣包的定價不能讓外觀變得比訂閱划算。

## 2. 金幣怎麼流動（目前的數值）

**拿到金幣**

| 來源 | 數量 |
|---|---|
| 每場對戰的分數 | 每 400 分 1 金幣，單場最多 80 |
| 贏一場 | 電腦 10–40（看對手等級）、分身 20、連線 25、排位 30 |
| 輸或平手 | 5 或 10 |
| 擊倒 | 每次 4，單場最多 20 |
| 每天第一勝 | 50 |
| 每日任務 | 三個，各 30–60 |
| 每日簽到 | 20 起跳，連續七天到 120 |
| 升段 | 40 起跳，段位越高越多 |
| 賽季結算 | 60 起跳，看最高段位 |
| 道場和開局課第一次過關 | 15、40–80 |
| 會員 | 以上全部再 +50%，簽到雙倍 |

**花掉金幣**

| 去處 | 價格 |
|---|---|
| 磚樣式 7 種 | 400–1,200，合計 5,500 |
| 牆面 7 種 | 500–900，合計 4,500 |
| 主題 6 種 | 600–1,000，合計 4,800 |
| 消行特效 3 種 | 600–800，合計 2,000 |
| 道具 | 每個 40–60 |

**粗估。** 一天打五場、任務做完、有簽到的玩家，大約拿 450–550 金幣。全部外觀合計 16,800 金幣，大約要玩一個月。道具是持續性的消耗：每場都帶滿 2 個，一場就花掉約 100 金幣，跟一場賺到的差不多。這些數字都是第一版，上線後要照實際資料調，原則是免費玩家一兩天能換到一樣東西，才有動力繼續打。

---

## 3. 公平性原則

1. 外觀只改長相，不改判定。方塊形狀、大小、碰撞都一樣。
2. 排位賽和連線對戰不能帶買來的道具。
3. 會員不給任何對戰上的好處。
4. 自己的圖片只存在玩家自己的裝置，不上傳、對手看不到。

這四條是之後加任何付費內容時的檢查表。

## 4. 要真的收錢，還缺什麼

現在整個遊戲是純前端，資料都存在玩家瀏覽器裡。這代表**會員資格和金幣現在改一下本機資料就能拿到**，試玩沒問題，收錢之前一定要改。

**需要的後端（一個小服務加一個資料庫就夠）**

| 功能 | 說明 |
|---|---|
| 帳號 | 登入，才能跨裝置、才能認得誰付了錢 |
| 訂閱狀態 | 金流服務付款成功後通知後端，後端記錄到期日；前端每次開啟時問後端 |
| 雲端存檔 | 金幣、擁有的外觀、段位搬到後端，前端只當顯示 |
| 排行榜、真人配對、真人排位 | 都需要伺服器做裁判 |
| 連線對戰的配對與中繼伺服器 | 目前都用 PeerJS 的公用伺服器，免費但不保證穩定；正式上線要自己架 |

程式裡已經留好位置：所有金幣和資格的判斷都在 `src/meta.js`，把裡面讀寫本機資料的地方換成呼叫後端即可，其他檔案不用動。

**金流怎麼接**

- 網頁版：台灣在地金流（例如綠界、藍新、TapPay），或是代收代付平台（例如 Paddle、Lemon Squeezy，由平台代為處理各國稅務）。各家支援的幣別、手續費和審核條件請以官方當下公告為準。
- App 版：走 App Store 和 Google Play 的內購，平台會抽成（一般落在 15%–30%，以平台當下規定為準）。
- 建議順序：先上網頁版加一家金流，驗證有人願意付，再考慮包成 App。

**上架通路**

1. GitHub Pages 或自己的網域（現在就能做）。
2. 加上 PWA 設定，讓手機可以加到主畫面。
3. 網頁遊戲平台（itch.io 等），多一個流量來源。
4. 用 Capacitor 之類的工具包成 App 上架商店。

## 5. 先看哪些數字

收費功能上線前，先看留存：

- 第 1 天、第 7 天還回來的比例
- 每人每天打幾場
- 打過排位的比例、開過商店的比例
- 開通體驗會員的比例（現在按鈕不收費，可以當成意願的參考）

留存不夠的話先修遊戲，不要急著開收費。

**跟另一個版本比較時**，除了總人數，建議看同樣的幾項：第 7 天留存、每人每天場數、平均單次遊玩時間。只看誰人多，容易被一次性的流量蓋過。

## 6. 風險

### 6.1 智財風險（最重要，收費前請先找律師）

這類落磚遊戲的權利人有主張過權利，而且贏過。2012 年美國紐澤西聯邦地方法院在 *Tetris Holding, LLC v. Xio Interactive, Inc.* 一案中，判定仿作《Mino》侵害著作權與商業外觀（trade dress）。被告主張自己只抄了規則和功能，法院沒有採納；法院認定的商業外觀包含「鮮豔、由四個等大方格組成的方塊」和「高比寬長的直立場地」。

本專案已經避開的：

- 名稱、標誌、任何原作的文字
- 美術：自己的磚牆主題、自己的配色（只有 T 是金色）、自己的介面配置
- 音樂和音效：全部是 CC0 素材
- 計分表和用語：自己訂的

仍然相同的：

- 十欄寬的直立場地
- 七種四格方塊的形狀
- 橫排填滿就消除的規則、落點預覽、暫存、預告下一塊

這些在玩家社群裡被當成這類遊戲的通用玩法，但上面那個判決顯示法院不一定這樣看。我不是律師，沒辦法判斷這個專案到底有沒有侵權；能確定的是，免費的練習作品和收費上架的商品，被追究的機率差很多。

想降低風險的方向（由低到高的改動幅度）：

1. 方塊的配色和形狀畫法再拉開（目前已經不同）。
2. 場地改成不同的比例，例如十二欄或更矮更寬。
3. 加入更多自己的方塊或自己的核心機制，讓道具和磚牆主題變成玩法的主體，而不是點綴。

### 6.2 平台下架

上架到 App 商店或遊戲平台後，只要權利人檢舉，平台通常會先下架再說。網頁版自己掌握網域，受影響較小。

### 6.3 連線對戰

目前的配對和中繼伺服器都是公用的，不保證可用；在管得嚴的網路（公司、學校）可能連不上。連線對戰沒有裁判伺服器，對手如果改程式作弊，目前擋不住，所以真人排位要等後端。

### 6.4 自訂圖片

圖片只存在玩家自己的裝置，不上傳也不分享，內容風險低。之後如果要做「分享我的牆面」，就需要審核機制。

### 6.5 不做的事

轉蛋、抽獎箱這類機率型販售不做。各地法規差異大，也容易傷害玩家信任。
