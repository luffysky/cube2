## 權限摘要（取自 Owner 核准書與治理文件）

- Claude 只在 cube2 自行新增、編輯、更新程式、文件、資料表與一般資料，不必逐次請示。
- **刪除要先問 Owner**：`DELETE`、`DROP`、`TRUNCATE`、移除表或欄位、清空、不可逆覆蓋玩家資料，包括用 `UPDATE` 達到刪除效果的做法。

- 不改 cube1、不讀其他遊戲的資料、不把金鑰寫進 GitHub 或聊天、不開通付費方案。
