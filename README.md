# 轉磚對戰

兩分鐘對戰的落磚遊戲。把方塊轉進洞裡，送對手一面水泥牆。

- 線上玩：開啟 GitHub Pages 後是 `https://luffysky.github.io/cube2/`（Settings → Pages → Deploy from a branch → `main` / `/ (root)`）
- 本機玩：在這個資料夾執行 `python3 -m http.server 8765`，打開 `http://127.0.0.1:8765/`

## 有什麼

**對戰**
- 排位賽：贏了升段，從陶土一路到窯神，段位越高電腦越強
- 挑電腦對手：五個等級，可以開道具戰，也可以帶買來的道具
- 連線對戰：開房間拿代碼或邀請連結，兩台裝置直接對打
- 分身對戰：每場自動錄影，回頭跟自己的紀錄打

**練功**
- 旋轉道場 13 關：T 轉的雙消、三消、蓋屋簷，還有 Z、S、L、J 的轉法
- 開局定式 3 課：開局 T 轉雙消、四消全清、雙消接三消（DT 砲）
- 自由練習（可悔棋、有旋轉雷達）、40 行競速

**成長與商店**
- 得分、金幣、每日任務、每日簽到、段位獎勵
- 商店：10 種磚、10 種牆面、7 種主題、4 種消行特效、5 套整套風格、7 種道具
- 會員（目前是體驗模式，不收費）：用自己的圖片當牆面和磚面

**其他**
- 介面語言：繁體中文、简体中文、English、日本語、한국어
- 鍵盤鍵位可以自己改；手機有觸控按鍵
- 手感可調：連續移動的延遲與間隔、軟降速度、落地鎖定時間

## 操作（預設）

| 動作 | 鍵盤 |
|---|---|
| 左右移動 | ← → 或 A D |
| 軟降、硬降 | ↓ 或 S、空白鍵 |
| 順轉、逆轉、轉半圈 | ↑ W X K、Z J Ctrl、Q L |
| 暫存、用道具 | C E Shift、F V Enter |
| 暫停 | Esc 或 P |

## 開發

```
node build.js        # 改完 src/ 之後重新產生 index.html
for t in engine score meta replay openers drills i18n; do node test/$t.test.js; done
```

沒有相依套件。檔案分工、怎麼加語言或外觀、測試怎麼跑，見 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。
商業模式、金幣數值、收費前還缺什麼、風險，見 [docs/BUSINESS.md](docs/BUSINESS.md)。
素材與第三方程式的出處見 [CREDITS.md](CREDITS.md)。

## 目前的限制

- 購買和會員是體驗模式，沒有接金流，資料存在玩家自己的瀏覽器。
- 連線對戰靠 PeerJS 的公用伺服器配對，不保證穩定；沒有裁判伺服器。
- 排位賽的對手是電腦。真人配對與真人排位需要後端。
