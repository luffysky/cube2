# 轉磚對戰

兩分鐘對戰的落磚遊戲。把方塊轉進洞裡，送對手一面水泥牆。

- 線上玩：<https://cube2-xi.vercel.app/>（Vercel，推到 `main` 會自動部署；有雲端存檔和排行榜）
- 本機玩（含雲端功能，資料庫在記憶體裡）：`npm install` 之後 `npm run dev`，打開 `http://127.0.0.1:8770/`
- 本機玩（純前端）：`python3 -m http.server 8765`，打開 `http://127.0.0.1:8765/`
- 也可以丟到任何靜態空間（例如 GitHub Pages）：沒有 API 的地方遊戲照常運作，只是進度留在裝置上、沒有排行榜

## 有什麼

**對戰**
- 排位賽：贏了升段，從陶土一路到窯神，段位越高電腦越強
- 挑電腦對手：七個等級，從第一次玩也贏得了的「新手」到 T 轉連發的「宗師」；可以開道具戰，也可以帶買來的道具。設定裡還能把所有電腦一起調慢或調快
- 連線對戰：開房間拿代碼或邀請連結，兩台裝置對打（正式站經由自己的伺服器轉送，4G 和 Wi-Fi 都連得上）
- 分身對戰：每場自動錄影，回頭跟自己的紀錄打

**練功**
- 旋轉道場 15 關：T 轉的雙消、三消、蓋屋簷，還有 Z、S、L、J 和長條的轉法
- 開局定式 3 課：開局 T 轉雙消、四消全清、雙消接三消（DT 砲）
- 自由練習（可悔棋、有旋轉雷達）、40 行競速

**雲端**（放在 Vercel 上才有）
- 雲端存檔：不用註冊，打完第一場自動開始存；金幣、段位、買過的東西由伺服器記帳，改本機資料沒有用
- 換裝置：舊裝置產生一次性的引繼碼，新裝置輸入就接上同一份進度
- 排行榜：段位、單場最高分、40 行競速，每月一季

**成長與商店**
- 得分、金幣、每日任務、每日簽到、段位獎勵
- 商店：10 種磚、10 種牆面、7 種主題、4 種消行特效、5 套整套風格、7 種道具
- 會員（目前是體驗模式，不收費）：用自己的圖片當牆面和磚面

**其他**
- 介面語言：繁體中文、简体中文、English、日本語、한국어（網址加 `?lang=en` 可以直接指定）
- 可以安裝成 App（PWA）：加到手機主畫面或電腦桌面，沒有網路也能打電腦和練功
- 各種螢幕都有對應的版面：小手機、平板直橫、筆電、桌機到 4K
- 鍵盤鍵位可以自己改；手機有觸控按鍵
- 手感可調：連續移動的延遲與間隔、軟降速度、落地鎖定時間

## 操作（預設）

| 動作 | 鍵盤 |
|---|---|
| 左右移動 | ← → 或 A D |
| 軟降、硬降 | ↓ 或 S、空白鍵 |
| 順轉、逆轉、轉半圈 | ↑ W X K、Z J Ctrl、Q L |
| 暫存、用道具 | C E Shift、F V Enter |
| 暫停 | Esc 或 P |

## 開發

```
npm install          # 只有兩個套件：Neon 的資料庫驅動，和測試用的記憶體版 Postgres
node build.js        # 改完 src/ 之後重新產生 index.html，連同 manifest、sw.js、robots.txt、sitemap.xml
npm test             # 規則、伺服器、前後端同步的測試（只需要 Node）
npm run dev          # 遊戲加 API 一起跑在 http://127.0.0.1:8770/
```

遊戲本身（`index.html`）沒有相依套件。檔案分工、後端怎麼運作、怎麼加語言或外觀、測試怎麼跑，見 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。
商業模式、金幣數值、收費前還缺什麼、風險，見 [docs/BUSINESS.md](docs/BUSINESS.md)。
素材與第三方程式的出處見 [CREDITS.md](CREDITS.md)。

## 目前的限制

- 會員是體驗模式，沒有接金流。
- 伺服器會重算每一筆金幣和段位，但「這一場打出幾分、誰贏」還是由玩家的裝置回報，只做合理範圍和時間的檢查。有心人仍然可以假造對局結果，排行榜要完全可信還需要重播驗證（見架構文件）。
- 暱稱沒有不雅字詞過濾；需要時可以在資料庫把玩家的 `ban` 設成 true，讓他從排行榜消失。
- 連線對戰沒有裁判伺服器；經由伺服器轉送，對手的畫面每秒更新幾次，不是即時的。
- 搜尋引擎和分享連結用的網址寫在 `build.js` 的 `SITE`（目前是 Vercel 給的網址）。換成自己的網域時改那一行再 build 一次。
- 勝利的歡呼音效授權還沒確認，見 [CREDITS.md](CREDITS.md)。
- 排位賽的對手是電腦。真人配對與真人排位還沒做。
